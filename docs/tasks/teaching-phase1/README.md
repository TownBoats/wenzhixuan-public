# 教学引擎一期：任务契约

日期：2026-11-25。源码基准：`a18d017`。状态：Q1–Q4 已定，产品代码未开始。
需求来源：[改动点整理](../improvement-points-2026-11-24.md)。实施细节：[任务与判据](TASKS.md)。
决策：[ADR-003 教学状态与引用](../../decisions/ADR-003-teaching-state.md)、[ADR-004 直接引导与教学方式](../../decisions/ADR-004-direct-guidance.md)。

## 1. 目标

让教学有计划、知道学生缺什么、能引用讲过的图，并在学生卡住时直接往前带一步。同时修复公式显示和候选答案缺少上下文的问题。

## 2. 用户已定事项（2026-11-25）

| 事项 | 决定 |
| --- | --- |
| 一期范围 | 快速修复 + 教学打底，布局放下一期 |
| 布局方向 | 左讲解右问题；窄屏为可切换的单栏 |
| 学习链路 11-03 撤销原因 | 提取质量不好、展示形式不好 |
| 直接教学形式 | 问题卡上的“直接讲给我”按钮，另有随时可切换的开关 |

## 3. 一期范围

| 任务 | 内容 | 依赖 |
| --- | --- | --- |
| T1 | 教学正文和问题磁贴的公式渲染 | 无 |
| T2 | 选项模型上下文 | 无；T5 后补充引用内容 |
| T3 | 卡住时直接引导（“直接讲给我”） | ADR-004 |
| T4 | 学习 plan、前置概念、概念抽取 | ADR-003 |
| T5 | 图与讲解的引用和跳转 | T4、ADR-003 |
| T6 | 集成验证与真实模型评估 | T1–T5 |

推荐顺序：T1 → T3 → T2 → T4 → T5 → T6。前三项可先单独交付，不等 T4。

**不做：** 新布局、用户消息改版、底部对话框调整、概念点击展开、选词提问、出题、复盘与串联、上下文压缩、因材施教、知识库、视频、跨会话学习档案。也不恢复已撤销的学习链路代码。

## 4. 完成判据

1. 公式在正文和问题磁贴中显示；货币写法不被误判为公式。
2. 候选答案能用到当前讲解和被引用的较早内容；生成失败时仍可手动作答。
3. 点击“直接讲给我”后，模型收到明确的“未作答、希望直接讲解”，与普通跳过可区分。
4. 新主题先有 plan 再展开教学；plan 可更新，学生在有待答题时也能要求调整；刷新后能恢复。
5. 概念不会仅凭学生自评变为“已验证”。
6. 能从正文或问题跳到被引用的图或讲解，再回到原处。
7. 旧会话能打开、续聊、备份、导出；既有单元测试与 `session-loop` 通过。

教学效果不能由自动测试证明，由 T6 的真实模型样本和用户验收判断。

## 5. 必须保持的不变量

以 `AGENTS.md` 的架构约束为准，本期特别注意：

- `src/agent/` 不读存储、不依赖 React；新数据由会话层以快照传入。
- 模型上下文只含状态合格、调用与结果配对的内容。
- 正常作答仍在最后一题处理完后开始下一轮；直接讲解和调整 plan 可提前续轮，但必须在一次原子转换中处理完其余待答题。
- 不新增存储键，不升 `schemaVersion`；新字段缺失时按旧语义处理。
- 副模型失败只影响候选答案，学生仍可手答。
- 生成图的 sandbox、CSP 和消息来源校验不变。

## 7. 19 条需求的分期

| 期 | 条目 |
| --- | --- |
| 一期 | 公式渲染、选项模型上下文、直接引导、学习 plan、前置概念、上下文跳转 |
| 二期：布局与教学方式 | 布局算法、引用问题（答题时并排看图）、用户消息升级、底部对话框、直接教学模式（开关） |
| 三期：概念与复盘 | 概念展开、针对讲解、概念串联、复盘、复盘形式（先 HTML）、出题 |
| 四期 | 压缩与摘要、因材施教；教学视频与知识库另立项 |

概念抽取在一期完成，是三期概念展开和串联的数据基础。长对话若已频繁超限，压缩应提前。后续各期只定方向，开工前另写契约。

## 8. Q1–Q4 结论（2026-11-25）

| ID | 问题 | 结论 | 来源 |
| --- | --- | --- | --- |
| Q1 | 多题时点“直接讲给我” | **立即开始**；其余待答题暂缓，见 ADR-004 | 立即开始由用户定；其余题处理由方案定 |
| Q2 | plan 是否要学生确认 | 不打断，学生可以要求调整；**有待答题时也能调整** | 用户定；后半句是落实所需 |
| Q3 | plan 放在哪里 | **页头下方常驻一行**，显示目标、当前概念和进度；点击展开浮层看全部并提出调整 | 用户交由方案决定 |
| Q4 | 直接教学开关 | 放二期，一期只做卡上按钮 | 用户同意 |

Q3 取舍：抽屉平时看不见，起不到定向作用；放消息流里会被滚走，学习链路已因展示形式被撤销。常驻一行占用小，展开不推动正文，窄屏只显示当前概念和进度。没有 plan 时不显示。二期并入左讲解右问题布局的概念路径。

## 9. 验证与中断

每个任务独立提交、独立可回退。按改动跑相关测试、改动文件 eslint 和构建；T3–T5 另跑 `session-loop`。T4 探针不通过时停在 T1–T3，不影响已交付部分。提交、推送、发布分别按用户授权执行。
