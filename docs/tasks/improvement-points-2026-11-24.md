# 问知轩改动点整理

日期：2026-11-24。状态：需求整理，未实施；分期见 [教学引擎一期契约](teaching-phase1/README.md)。

改动点分为两个方面：

- **布局、渲染与界面（看得见）**：UI、可视化、布局、流程设计等。
- **教学引导与推理引擎（看不见）**：建模、Agent 运行、上下文组织等。

跨两个方面的条目放在主要一侧，并注明另一侧。

## 一、布局、渲染与界面

### 1. 布局

**布局算法**
把 chatbot 传统的文本滚动形式改成另一种布局算法，在布局上做创新。

**底部对话框优化**
学习触发以后，底部对话框就没用了。考虑移除，或者换一种形式。

### 2. 消息与引用

**用户消息升级**
目前直接以文本气泡展示用户回答的问题和答案，缺乏设计感，也没有有效利用屏幕空间。

**上下文跳转**
讲解或问题需要参考之前某个轮次的讲解图（或内容）时，要往上滑，上下文过长就找不到。可以考虑由 AI 给出提示，点击跳转到需要引用的图。

**引用问题**
问题卡片（悬浮框）会引用对话内容中的图。只看问题显得干巴，学习者要不断往上翻上下文，增大记忆负担，不利于学习。希望找到一种机制减少这种情况（通过布局来优化）。

### 3. 概念交互

**概念展开**
抽取教学中的概念实体，通过点击“展开”对该概念的教学。（另一侧：概念实体抽取）

**针对讲解**
选中某个概念提问（利用悬浮窗等），不新增到对话上下文。（另一侧：独立于对话的上下文）

### 4. 渲染

**公式渲染**
`$2\log_2(n+1)$` 这类符号不能渲染。

## 二、教学引导与推理引擎

### 1. 教学规划与诊断

**学习 plan**
学习之前制定 plan，根据 plan 确定大致的教学方针（可以融入知识库），防止 AI 的教学乱飘。plan 可以动态更新。

**前置概念**
根据用户的回答判断其是否知道前置概念，减少 AI 以为的“默会知识”。

**因材施教**
将人格测量、荣格八维等融入讲解，提供学生更偏好的讲解方法。

### 2. 引导方式

**增加直接引导**
用户没办法思考或想不到时，更想让 AI 直接讲解一个点，因为用户缺乏一些知识，无法推导。

例如，1+1=2 很简单，不可能不会；那么 1×3 = 1+1+1。这种就是递进关系。

**直接教学模式**
一直让用户自己思考、推理（不直接告诉答案），可能会增加输入阻力。考虑做一个直接提出解答、减少提问的模式，同时能运用现有的教学组件模块。

### 3. 检验

**出题功能**
检验学习者是否学会。它和提问不一样，可以做一些选择题，独立于上下文。（另一侧：题目界面）

### 4. 复盘与串联

**复盘**
阶段性总结、复盘对话。上下文过长会导致学习者不断翻阅上下文，在有限的屏幕上容易丢失注意力和联系。可以植入 skill 和 UI 机制用于复盘，并基于此做可视化。（另一侧：复盘 UI 与可视化）

**概念串联**
对话中散落着知识点，难以回溯复盘。需要一种形式把整轮学习串联起来。（另一侧：串联的呈现形式）

**复盘形式**
一轮学习完成以后，可以提取其中的概念、教学路径，形成一次教学副本，可以是 HTML、某种蓝图，也可以是教学视频。一方面供自己复盘，另一方面利于社媒传播。（另一侧：副本的视觉呈现）

### 5. 上下文管理

**压缩与摘要**
对上下文进行压缩、摘要。

**选项模型上下文优化**
问题回答模型应该注入怎样的上下文？

- 可能需要模型判断怎样才能做到正确回答；如果模型的提示有误，反而会影响正确的学习效果。
- 需要有必要的上下文才能进行回答。
- 如果问题牵涉到对话内容（可能是好几轮之前的内容），需要往选项模型的上下文中注入内容。
