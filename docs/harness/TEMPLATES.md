# Harness 最小记录模板

模板按任务风险选用，不要求每次变更生成全部文件。正文应引用代码、决策和证据，避免相互复制。复制到其他项目时替换路径、角色和检查命令。

## 1. 任务契约

```text
任务 ID / 名称：
目标与触发场景：
本次授权范围：
交付物：
完成判据（可观察行为）：
相关不变量 / 数据兼容要求：
影响模块：
主要未知与验证办法：
需要用户决定的取舍：无 / 问题与选项
验证计划：
回退或中断方式：
关联决策 / 证据：
```

低风险修复可以在交付说明中写完这些关键信息；跨层或迁移任务再独立保存。

## 2. 决策记录（ADR）

```text
ID / 标题 / 日期：
状态：提议 / 已接受 / 已替代 / 已撤销
决策人及授权依据：
问题与约束：
考虑的选项：
结论与理由：
放弃选项及代价：
影响的接口 / 数据 / 文件：
替代：旧 ADR ID（若有）
验证证据：
遗留风险及后续条件：
```

决定变化时追加新 ADR，并在现行索引中说明替代关系。历史记录保留当时判断；修正事实与推断要写成勘误，不静默重写原始理由。

## 3. 验证证据

```text
证据 ID / 日期 / 执行者：
任务与判据：
类型：静态 / 单元 / mock / 假服务 / 浏览器 / 真实端点 / 发布检查
源代码：commit SHA + 工作树差异说明
环境：运行时、工具版本、平台；不要填写密钥
产物：构建来源 / 版本 / 校验值（若涉及）
动作或原始命令：
退出码与实际结果：
原始输出位置：
可以支持的结论：
未覆盖范围：
失败分类：业务断言 / 环境 / 测试自身 / 外部服务 / 未知
下一步或解除条件：
```

输出过长时保存独立证据文件，交接只记摘要和位置。结果带日期与基准；旧输出可以引用，不能冒充新提交已复验。真实模型配置只记录必要的非敏感标识，密钥与请求正文中的凭据不归档。

## 4. 验收与阶段关闭

```text
阶段 / 范围：
代码基准：
交付行为：
实现状态：
验证状态及证据 ID：
人工验收：验收人、日期、明确表态、覆盖范围
未覆盖 / 被接受的限制：
遗留事项：ID、影响、下一动作、解除条件
Git 状态：已提交 / 未提交；分支与范围
发布状态：未发布 / 版本与时间 / 已回退
知识更新：现行协议、业务规则、ADR 索引
归档位置：
下一阶段：未定义 / 明确任务
```

“验收通过”只表示该范围被接受。自动验证、发布与遗留事项分别记录。

## 5. 当前 HANDOFF

```text
# 当前交接
更新时间 / 代码基准 / 工作区状态

## 当前状态
已关闭阶段；当前主要任务；实现 / 验证 / 验收 / 发布状态。

## 下一步
一个可直接执行的第一动作，写清输入和成功条件。

## 待决策与未关闭问题
ID | 问题与影响 | 已知事实 / 不确定性 | 下一动作与解除条件

## 证据和知识入口
任务、协议、ADR、验证和历史归档链接。

## 最近一次交付
本次改动、实际检查、未完成部分。只留接续所需摘要。
```

当前状态可覆盖更新；详细日志进入任务证据或阶段归档。中断时优先保存已改文件、是否可用、失败输出位置和接手第一步。

## 6. 归档清单

```text
归档主题与日期：
范围与排除项：
源代码基准：
原件 / 快照路径映射：
完整性校验文件与方法：
敏感资料处理：原始配置与密钥排除；原始记录公开前另行审阅
旧规则退出加载位置：
新规则 / 新交接 / 现行知识入口：
已知矛盾与勘误位置：
Git 跟踪及发布状态：
```

若历史资料只有本地副本，必须明确说明。复制归档与提交归档是两个操作，不在完成复制时声称资料已进入远端版本控制。
