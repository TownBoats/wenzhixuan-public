## 使用原则

开始工作先看短交接，再按任务读业务知识和代码。追溯理由或证据时才进入归档。历史方案中的命令、阶段门槛和禁改白名单已结束，不自动限制下一阶段。

业务事实以现行实现核对，出现与知识文档不一致时应报告并同步更新；目标设计或待实现方案必须明确标注。验证证据带日期与代码基准，人工验收、自动回归和发布状态分别记录。

新知识可以覆盖更新当前事实；ADR 和冻结历史采用追加说明记录变更。不要把完整日志不断叠加进 HANDOFF，也不要同时维护多份相同规则正文。
