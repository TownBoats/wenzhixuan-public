「结果」与「现象」来自用户 2026-10-16 的实测口述（原话：「都没问题」「3 张问题卡片、自动发起、重试了我指定的最后一条」）。

## 5. 采集方式与限制（写给后续会话）

- 本会话 shell 会把超过约 10 秒的命令判定为长驻进程并截断输出 → 长命令需后台执行并把结果落盘后再读。
- 批量删除会触发 IDE 安全删除守卫（`SAFE_DELETE_BULK_CONFIRM_REQUIRED`）→ 依赖清理必须在用户自带终端执行，不要用环境变量绕过守卫。
- 浏览器走查只能由用户完成，AI 无法代做；因此走查项必须写清「操作 → 观察点」，不能只写"看是否正常"。
