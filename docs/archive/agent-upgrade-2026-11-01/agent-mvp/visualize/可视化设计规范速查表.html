可视化设计规范速查表

内联图表与示意图的完整设计系统：配色、排版、坐标、类型路由。

适用范围：SVG 示意图 / HTML 交互组件 / 数据图表　·　整理于 2026-10-19

01核心原则

这五条决定了所有细节规则的方向。

  1. 无缝：用户不该察觉宿主界面在哪里结束、图形在哪里开始。外层容器永远透明，背景由宿主提供。
  2. 扁平：不用渐变、网格背景、噪点纹理、装饰性效果。靠留白和层级区分，不靠特效。
  3. 紧凑：关键内容内联展示，其余用文字说明。一张图塞满解释是最常见的失败。
  4. 文字归文字，视觉归视觉：所有解释、引言、总结写在正文里，图形里只放标签。
  5. 克制：字号只用两档字重（400 / 500），配色最多两个色系，一层最多四个盒子。

02流式渲染约束

代码是逐字流出的，结构要让"有用的内容"尽早出现。

输出顺序

  • HTML：短 <style> → 内容 → <script> 放最后
  • SVG：<defs>（marker）→ 视觉元素立即出现
  • <style> 控制在 15 行以内

为什么

  • 渐变、阴影、模糊在流式 diff 时会闪烁
  • 优先内联 style="..." 而非样式块，保证中途状态就是对的
  • 输入框、开关等控件必须在中途就长得正确

03硬性禁止项

这几条是红线，破一条整张图的质感就塌了。

  • 禁止 注释（<!-- --> / /* */）——浪费 token 且打断流式
  • 禁止 小于 11px 的字号
  • 禁止 emoji——用 CSS 形状或 SVG path 替代
  • 禁止 渐变、投影、模糊、发光、霓虹
  • 禁止 外层容器深色或彩色背景（必须透明）
  • 禁止 position: fixed
  • 禁止 600 / 700 字重，只用 400 / 500
  • 禁止 标题式大写（Title Case / ALL CAPS）
字体规格：h1 = 15px，h2 = 14px，h3 = 13px，全部 font-weight: 500；正文 13px / 400 / 行高 1.6。

颜色和圆角一律走变量，不写死值——这样浅色 / 深色主题能自动适配。

06SVG 搭建规则

画布的坐标系是固定的，所有尺寸都从它推算。

viewBox
固定 "0 0 680 H"，680 不可更改——它是所有坐标计算的基准
width
根节点写 width="100%"
H（高度）
= 最下方元素的底边 + 20px，不要猜
安全区
x = 40 → 640，y = 40 → (H − 40)，背景透明
单次输出
一次调用只产出一张 SVG
文字方向
不允许旋转文字
描边
图形边框与连线统一 0.5px
连接线
凡是当连线用的 <path> / <polyline>，必须写 fill="none"，否则会变成巨大黑色色块

箭头 marker（每张 SVG 的 defs 里都要有）

<defs>
  <marker id="arrow" viewBox="0 0 10 10" refX="8" refY="5"
    markerWidth="6" markerHeight="6" orient="auto-start-reverse">
    <path d="M2 1L8 5L2 9" fill="none" stroke="context-stroke"
      stroke-width="1.5" stroke-linecap="round" stroke-linejoin="round"/>
  </marker>
</defs>

09三类图形的画法要点

流程图

  • 单方向流动优先，最多 4–5 个节点
  • 循环不画成圈，改用分步器
  • 同类型节点等高

结构图

  • 最外层圆角 20–24，最浅填充
  • 内层圆角 8–12，次一级填充
  • 每层容器内留白至少 20px，最多嵌套 3 层

示意 / 直觉图

  • 物理对象画简化的剖面或切面
  • 抽象概念发明空间隐喻（哈希 = 漏斗撒入桶）
  • 颜色编码强度，不编码类别：暖色 = 热 / 活跃，冷色 = 静 / 休眠
  • 标签放在对象外部，用细引导线连接
  • 有控件就做成可交互，不要静态

动效许可

  • 整张图最多一个 <linearGradient>（仅限连续物理量）
  • @keyframes 只动 transform 和 opacity，周期 2 秒内
  • 必须包在 @media (prefers-reduced-motion: no-preference) 里

10无障碍

  • HTML 组件：开头放一个视觉隐藏的 <h2 class="sr-only">，写一句话摘要。
  • SVG：根节点加 role="img"，并把 <title> 和 <desc> 作为第一个子元素。
  • 本地图片：直接用绝对路径引用（<img src="/abs/path.png">），宿主会自动改写，不要手写 base64。
这份规范的底层逻辑只有一句：把"好看"翻译成可以计算的约束。坐标、间距、字号、色阶全部有公式，所以不需要审美判断也能稳定出图。
