# ADR-005：重试时旧问题作废

日期：2026-11-25。状态：已接受，已实施。依据：用户明确“旧的题作废，只保留显示”。

**问题：** 重试后旧的待答题仍可作答，并与新题一起阻塞续轮。

**结论：** 重试时该轮已有问题全部标记 `resolution:'superseded'`，待答的转为 `skipped`。它们只显示，不可作答，不进入答案汇总；TXT 保留题干，不写成学生跳过。

**取舍：** 不新增问题状态，因为旧版本会把未知状态还原成 `pending`；附加字段会被旧版本丢弃，显示为普通跳过。不改存储键与 `schemaVersion`。端点在重试中复用 toolCallId 时，新题取代旧题。

**边界：** 此前已落盘、重试后残留的旧待答题不迁移，仍按原行为作答。替代知识文档中“旧 pending 保留”的历史语义。[ADR-004](ADR-004-direct-guidance.md) 的 `resolution:'explain'` 沿用同一字段。
