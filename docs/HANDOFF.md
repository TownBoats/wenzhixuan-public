- 已在设置顶部增加“数据备份与迁移”：导出 JSON、选择文件、预览和确认合并。
- 覆盖 v2/v1 会话、学生答案/待答问题、图示、模型配置、提示词、偏好及提示关闭状态。
- 兼容保留旧学习记录键，不恢复已撤销的学习链路运行或界面。
- 默认完整备份包含接口地址和 API Key；始终提示未加密，可取消包含凭据。
- 不含凭据时排除模型连接详情；导入保留目标设备的连接地址和密钥。
- 只备份显式业务键，不枚举 origin 的其他数据；草稿和临时 reasoning 不导出。
- 原始损坏存储也可导出抢救，但损坏集合无法直接导入；不假装已完整恢复。
- 支持版本化备份与旧版 v1 数组，文件大小限制 50 MB；格式与版本校验后才预览。
- 各历史集合按 ID 合并，较新时间胜出，相同时间保留本机；本机独有条目保留。
- 文件缺省键不清空，设置按包含键覆盖；不传播删除、不合并同会话分叉轮次。
- 这是文件迁移/手动同步；没有新增账户、云存储或后台自动同步。
- 导出/应用导入前检查当前会话已保存，运行中禁用；失败可重试，保留重命名标题。
- 导入预览不写入；多键写入失败尝试逆序回退，回退失败单独提示。
- 导入后用会话命令重读当前会话与历史，配置/表单/等待偏好同步更新，草稿保留。
- 导入不会刷新页面或自动重发模型请求；v2 使用现有存储清洗和恢复逻辑。
- 日常历史键与 schemaVersion 不变，没有批量迁移旧数据、清空存储或更换依赖。
- 原上下文窗口显示、三工具与教学闭环继续保留；本轮未更改运行层协议。
